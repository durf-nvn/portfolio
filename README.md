# Novin Durf N. Aguilar: Portfolio

React + TypeScript (TSX) + Vite.

## Run locally
    npm install
    npm run dev

## Deploy to Vercel
1. Push this folder to a GitHub repo.
2. In Vercel: Add New > Project > import the repo.
3. Vercel detects Vite automatically (Build: `npm run build`, Output: `dist`). Click Deploy.

## Where to edit
- Text content: `src/data.ts`
- Colors and layout: `src/index.css` (colors are the CSS variables at the top)
- Certificate images: `public/certs/`
- Portrait (background removed): `public/images/portrait.webp`
